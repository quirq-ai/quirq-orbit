One repo, one branch per experiment. This branch, main, is the index, and archive keeps the finished ones.

How it works

Every experiment starts as a folder. ./publish turns each folder into a branch:

  • Branch name = folder name. The innernet/ folder is the innernet branch.
  • Branch root = folder contents. Clone a branch and you have the folder back.
  • Names can be paths. The agentic-ai/autoquirq/ folder is the agentic-ai/autoquirq branch. A folder that holds experiments, like agentic-ai/, is just a group and never a branch of its own.
  • Branches are orphans. They share no history with each other or with main.
  • Commits append. Publishing never rewrites a branch: each snapshot is a new commit on top, so a branch's log is that experiment's history. A plain ./publish adds one only when the folder changed; naming the experiment (./publish trees) adds one even when nothing did. The author date is when the folder last changed.
  • Ignored files stay home. The folder's own .gitignore applies, and .publishignore always wins on top of it: dependencies, build caches, .env files, local state. Files over GitHub's 100 MB limit are left out and named in the commit message.
  • Untouched clones become pointers. A folder that is a clean clone of someone else's repo publishes a README with the upstream URL and exact commit instead of a copy.
  • Finished experiments get compressed into archive. ./archive squashes a branch into one commit on top of the archive branch, then deletes the branch. That commit holds only the experiment's final files, at the root, so the archive tip is the newest archived experiment and each commit back (archive~1, archive~2, ...) is the one archived before it. Earlier snapshots of the branch are not kept.

Get an experiment

git clone --single-branch -b <name> https://github.com/quirq-ai/experiments.git <name>

Archived ones live one per commit on archive. Clone it and step back through them:

git clone --single-branch -b archive https://github.com/quirq-ai/experiments.git archive
git -C archive checkout HEAD~1   # one experiment further back each time

Publish, archive and rename

Clone main, keep experiment folders inside it, then:

./publish                # every folder; pushes what changed, then this index
./publish innernet rea   # only these folders; always a new commit each
./publish --dry-run      # show what would happen; write and push nothing
./archive trees          # compress a finished experiment into the archive branch
./archive --dry-run trees
./rename autospawn-clone agentic-ai/autoquirq
./rename --dry-run autospawn-clone agentic-ai/autoquirq

Renaming moves the folder, the branch and the index entry together, and the branch keeps its history. The new name can be a path: missing folders like agentic-ai/ are created, and a group left empty is removed.

Archiving leaves the local folder alone, and ./publish skips archived names from then on. It refuses when the folder has changes that were never published (publish first, or --force to archive the published version). To revive an experiment, move its entry from archived back to experiments and publish it: it starts a fresh branch, and its archived commit stays where it is.

Descriptions and stack labels live in experiments.json: edit them there and the next publish rewrites the table. Folders listed under skip never get a branch. Clones of repos owned by an account under owners are always copied, never turned into pointers.

./publish only builds on commits it made itself. If a branch gets commits from anywhere else, it stops rather than snapshot over them; --force overrides that.
