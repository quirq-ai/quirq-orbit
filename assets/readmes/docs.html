qq docs

The docs for qq, quirq's build and release infrastructure, are live at docs.quirq.dev. XO Space docs are at docs.xo.builders. New here? Start at docs.quirq.dev/docs, which says what qq does and which guide to read first. The rest of this file is for people working on the docs site itself.

The videos in public/videos/ are rendered from real qq runs by the scripts in scripts/videos/.

Run development server:

pnpm dev

Open http://localhost:3100 with your browser to see the result.

Explore

In the project, you can see:

  • src/lib/source.ts: Code for content source adapter, loader() provides the interface to access your content.
  • src/lib/layout.shared.tsx: Shared options for layouts, optional but preferred to keep.
Route Description
src/app/docs The documentation layout and pages.
src/app/api/search/route.ts The Route Handler for search.
src/app/api/chat/route.ts The Route Handler for AI chat.
src/app/og/docs OG image generation for docs pages.
src/app/llms.txt LLM-friendly plain text content route.
